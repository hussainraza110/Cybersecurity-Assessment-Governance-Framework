# Image Asset Catalogue

> **Implementation note:** This organization-neutral framework document must be tailored, reviewed, and approved before operational adoption. Replace bracketed fields and validate applicable legal, regulatory, contractual, and sector-specific requirements.

## 1. Purpose

This catalogue lists the framework's visual assets and their intended use. PNG files are convenient for Markdown rendering and presentations; corresponding SVG files are scalable vector source assets.

## 3. Use and maintenance

- Keep the SVG and PNG versions synchronized.
- Update diagrams when governing methodology or procedures change.
- Do not treat diagrams as independent policy requirements.
- Use descriptive alternative text when embedding images.
- Verify labels and process order against the current Markdown source before publication.
